# dss-g1

*Descripción del Proyecto*

Este proyecto tiene como objetivo principal la creación de una plataforma web que facilite la gestión de reservas en un gimnasio. La aplicación permitirá a los usuarios inscribirse en clases, gestionar su historial de reservas y comunicarse con el personal del gimnasio de manera eficiente. Además, incluirá funcionalidades que mejoren la experiencia del usuario y fomenten la interacción entre los miembros del gimnasio.

## Funcionalidades

### *1. Reserva de clases*
- Consulta y visualización de clases disponibles.
- Reserva y cancelación de clases.
- Notificaciones por correo electrónico al realizar o cancelar una reserva.

### *2. Historial de reservas*
- Acceso a un historial de clases reservadas previamente.
- Opción de volver a reservar clases desde el historial.

### *3. Contacto directo con el equipo de mantenimiento*
- Sistema de comunicación para reportar incidencias o solicitar mantenimiento en las instalaciones del gimnasio.
- Seguimiento del estado de las solicitudes enviadas.

### *4. Solicitudes de entrenadores personales*
- Posibilidad de solicitar sesiones personalizadas con entrenadores disponibles.
- Confirmación y gestión de las sesiones reservadas.

### *5. Foros*
- Espacio donde los usuarios pueden compartir experiencias, plantear dudas y recibir recomendaciones de otros miembros y entrenadores.
- Moderación de contenidos para garantizar un ambiente seguro y respetuoso.

### *6. Registro e inicio de sesión*
- Creación de cuentas para usuarios y administradores.
- Acceso seguro mediante autenticación.

### *7. Cola pública de música (JAM)*
- Funcionalidad que permite a los usuarios sugerir canciones para la ambientación musical del gimnasio.
- Votación de canciones por parte de los usuarios para determinar el orden de reproducción.


Este proyecto busca optimizar la experiencia de los clientes del gimnasio, facilitando la organización de las clases y promoviendo una mayor interacción entre los usuarios y el personal.
